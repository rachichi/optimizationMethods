# Optimization Methods

Coursework for Optimization Methods (ORIE 5380) at Cornell Tech, Fall 2026.

## Skills showcased

- **Linear and mixed-integer programming (MIPs) in Gurobi:** writing decision variables, constraints and objectives in `gurobipy`, and building models from data with loops instead of one constraint at a time.
- **Integer programs:** solving a covering problem, and showing why rounding a linear-program solution can give an infeasible plan.
- **Network flow:** feasible flows, minimum-cost flow, dummy nodes for excess supply, and maximum flow with the matching minimum cut.
- **Reading results:** solver logs, binding constraints, the MIP gap, and bounds from the dual.
- **Checking AI-assisted models:** using an LLM to help formulate and debug a model, then verifying its answer with the solver.
- **Tools:** Python, Jupyter, Gurobi.
